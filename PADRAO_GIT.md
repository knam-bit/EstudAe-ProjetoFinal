# Padrão de Git e Commits — EstudAe

## 1. Convenção de branches

- main: versão principal e estável.
- feature/nome: desenvolvimento de funcionalidades.
- fix/nome: correção de erros.

Exemplos:
- feature/tela-inicial
- feature/viewmodel-tarefas
- feature/retrofit
- fix/navegacao

## 2. Padrão de commits

- feat: nova funcionalidade.
- fix: correção de erros.
- refactor: reorganização do código.
- docs: atualização da documentação.
- test: inclusão ou alteração de testes.

Exemplos:
- feat: adiciona tela inicial
- fix: corrige navegacao
- docs: atualiza documentacao

## 3. Organização do trabalho

1. Criar uma branch para cada funcionalidade.
2. Realizar as alterações na branch correspondente.
3. Testar as modificações.
4. Criar commits padronizados.
5. Enviar a branch ao GitHub.
6. Criar um Pull Request para a main.

## 4. Objetivo

Organizar o desenvolvimento, facilitar a colaboração
entre os integrantes e preservar a estabilidade do projeto.
